8. What does git revert do, and how can you use it?
	- git revert creates a new commit that undoes the changes made in a chosen commit, ignoring other commits. It can be used to undo undesired changes without affecting later desired changes
9. What does git reset do, and how can you use it?
	- git reset undoes all commits made after a chosen commit. It can be used to undo the most recent uncommitted changes if undesired changes were made consecutively
